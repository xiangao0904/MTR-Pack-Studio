# Project instructions

- Think from first principles. Communicate in clear, natural language.
- Use Rust and Tauri for the desktop backend, Vue 3 and TypeScript for the UI.
- Keep user-facing strings behind the i18n interface. English is the only shipped language in the first release.
- Make atomic Git commits: each commit should cover one coherent change and leave the repository in a reviewable state.
- Write Git commit subjects and bodies in English.
